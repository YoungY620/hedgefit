## Long description

Describe an asset, portfolio, or investment thesis. HedgeFit separates wanted and unwanted exposures, researches Polymarket and Kalshi candidates, evaluates causal fit, settlement rules, timing, liquidity, cost, and basis risk, then produces a table-first report with concrete holdings. It is a research workflow only and never places or prepares trades.

## Release notes

Initial public release. Includes the semantic hedging workflow, Asset Capsule, hedge-fit scorecard, prediction-market research boundaries, source requirements, and concrete holdings report template.

## Submission boundary

The plugin is read-only research guidance. It requests no credentials, has no MCP server, does not authenticate, and does not place, prepare, sign, or submit orders.
